# Zehin — Pikirlenişiňi syna

Интерактивный тест мышления на туркменском языке: 20 вопросов, 15 минут, 4 направления
(логика, математика, фигуры, последовательности). Результат — условный IQ-показатель.

## Запуск

```bash
npm install
npm run dev       # dev-сервер: http://localhost:5173
npm run build     # продакшн-сборка в dist/
npm run preview   # просмотр собранной версии
```

## Страницы

| Путь           | Описание                                              |
| -------------- | ----------------------------------------------------- |
| `/`            | Приложение: главная → тест → результат               |
| `/design.html` | Дизайн-система: палитра, типографика, компоненты     |

## Структура

```
zehin/
├── index.html              # приложение
├── design.html             # страница дизайн-системы
├── public/favicon.svg
├── vite.config.js          # multi-page сборка
└── src/
    ├── main.js             # точка входа приложения, навигация и таймер
    ├── design.js           # точка входа дизайн-системы
    ├── state.js            # состояние сессии теста
    ├── data/               # вопросы, категории, тренировочные задания, тексты
    ├── lib/                # dom-хелперы, форматирование времени, подсчёт результата
    ├── components/         # диалоги, варианты ответа, карточки, toast
    ├── screens/            # home / test / result
    └── styles/
        ├── tokens.css      # цвета, шрифты, радиусы, отступы
        ├── base.css        # сброс и базовая типографика
        ├── layout.css      # контейнер, шапка, подвал
        ├── main.css        # общий вход стилей
        ├── components/     # brand, button, answer, progress, card, dialog
        └── pages/          # home, test, result, design
```

## Дизайн

- **Цвета:** фон `#101715`, панели `#19221e`, линии `#303a33`, акцент `#c4f578`.
- **Шрифты:** Manrope (заголовки), DM Sans (текст), Space Mono (метки и данные), Georgia italic (акцент).
- Все цвета и шрифты — CSS-переменные в `src/styles/tokens.css`.

## Подсчёт результата

`условный IQ = 70 + 3 × количество верных ответов` (от 70 до 130).
Это учебный показатель, а не стандартизированный IQ-тест.
